# Public API captures

Reduced public WordPress responses captured on 2026-10-28 from the original www.24hd.today website:
posts (latest/movie/Chinese series) with `_embed=wp:featuredmedia`, and categories filtered by the Chinese-series slug.
Only fields used by the catalog are retained; featured-media objects contain source_url only.
Player embed URLs come from ACF fields; no expiring player/media responses or cookies are included.
The series capture has twelve published episode links; its title's larger episode count is not treated as available playback.
